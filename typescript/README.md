# malawi_plate

Malawi's licence plates for the plate_core library — the private plate, two letters and four digits in silver on black, with one theme and an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/malawi/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/malawi';

const spec = country.specs.get('mw.private');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `mw.private`

## Themes

- `MalawiThemes.private`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`MalawiValidator`).
