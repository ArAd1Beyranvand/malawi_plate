# malawi_plate

Malawi's licence plates for the plate_core library — the private plate, two letters and four digits in silver on black, with one theme and an advisory validator.

## Quick start

### Install (Python)

Copy `python/plates/countries/malawi/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.malawi.data import SPECS, THEMES

spec = SPECS["mw.private"]
theme = THEMES["MalawiThemes.private"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `mw.private`

## Themes

- `MalawiThemes.private`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `MalawiValidator` to classes.
